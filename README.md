# rsschool-landing page

## Coffee House: Landing Page

Responsive two-page landing page for a coffee house, built for RS School (Part 1) with plain HTML, CSS and JavaScript.

**Live demo:** [Link to deployed page](https://mirlanbeck.github.io/rsschool-landing-page/)

## Pages

- **Home:** hero, "Choose your favorite coffee" slider, About gallery, Mobile app section, footer with contacts.
- **Menu:** Coffee, Tea and Dessert tabs with product cards.

## Features

- Responsive layout checked at 1440px, 768px and 380px, with fluid sizing in between.
- Light and dark themes: the toggle in the header saves your choice in `localStorage`, keeps it when you switch pages, and follows your system setting the first time.
- Accessible markup: semantic HTML, keyboard-friendly tabs and controls, visible focus styles.

## Tech

HTML5, CSS3 (custom properties, grid, flexbox, `clamp()`) and vanilla JavaScript. No frameworks or libraries.

## Run locally

Open `index.html` in a browser, or use any static server such as the VS Code Live Server extension.
